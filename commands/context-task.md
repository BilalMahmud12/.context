---
description: Load comprehensive context for a specific task
---

Reads and displays:
1. Task file content (plan, specifications, steps)
2. Files in scope (create/modify/delete)
3. Current git branch and status
4. Recent commits touching task files
5. Dependencies mentioned in task

Usage: /context:task [task-id]

Useful when:
- Resuming work after time away
- Understanding task dependencies
- Preparing to start a task

Example: /context:task 003
