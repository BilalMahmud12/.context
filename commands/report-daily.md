---
description: Generate daily work summary report
---

Creates markdown report with:
1. **Tasks Completed** - From git commits and state updates
2. **Tasks In Progress** - Current task status
3. **Commits Made** - Today's commits with summaries
4. **Files Changed** - Stats on modifications
5. **Key Changes** - Notable updates

Usage: /report:daily

Output: docs/sessions/reports/YYYY-MM-DD-daily.md

Useful for:
- Daily standup preparation
- Time tracking
- Progress documentation
